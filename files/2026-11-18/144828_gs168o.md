# 泛读论文清单（50 篇）— AI 原生应用开发架构方向

> **主题小组：一、AI 原生应用开发架构**
>
> - 第 1–5 篇：既有推荐论文（覆盖概念定义、参考架构、RAG 运行架构、Agent 可观测性、Agent 应用测试实践）
> - 第 6–50 篇：新增检索论文（45 篇），全部经 arXiv 官方 API 核实真实存在，元数据（标题/作者/日期/发表状态）直接取自 arXiv 记录
>
> **检索与筛选方法**：
> 1. 通过 arXiv API 以 18 组检索式（AI-native applications、LLM-integrated architecture、RAG survey/ops、LLM agents framework、AgentOps/observability、LLM app testing、guardrails/security、multi-agent orchestration 等）检索，获得 **734 篇**去重候选（已剔除既有 5 篇）；
> 2. 按脚本对「主题直接性、实证强度、发表状态、时效性」加权评分，取前 160 篇进入人工复筛；
> 3. 人工按 6 条筛选标准精选 45 篇，保证子方向组合覆盖、避免研究问题高度重复，并保留相反/互补结论（如第 27、37 篇的批判性发现）。
>
